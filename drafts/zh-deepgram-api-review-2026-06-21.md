# Deepgram API 测评 2026：Nova-3 语音识别 + Aura-2 语音合成

## 介绍

Deepgram 成立于 2015 年，是以 API 为先构建的语音 AI 平台。其 Nova-3 STT 模型和 Aura-2 TTS 模型均为业界领先水平，支持 50+ 语言，延迟低于 300ms。

## 产品线

STT: Nova-3 单语（最佳英文精度）、Nova-3 多语（50+ 语言含中文）、Flux（对话优化）、Whisper（开放模型）
定价：$0.0043-0.0077/分钟

TTS: Aura-2（$0.030/千字符）、Aura-1（$0.015/千字符），7 种语言不含中文

## 定价

即用即付，$200 免费额度，成长计划 12-20% 折扣，初创企业计划最高 $100K。

## 优缺点

优点：最佳 STT 精度、亚 300ms 延迟、$200 免费额度、50+ 语言、自托管、SOC 2/HIPAA 合规。

缺点：TTS 无中文、无国内数据中心、无联盟计划。

## 总结

追求 STT 精度的开发者首选。Nova-3 性价比最高的英文语音识别 API，自托管选项是企业亮点。
