# Weaviate Cloud 2026：开源向量数据库与混合检索深度评测

Weaviate 是 Apache 2.0 开源的向量数据库（github.com/weaviate/weaviate），首创了生产级混合检索（Hybrid Search）——在一个查询中同时融合 BM25 关键词打分与向量相似度。2026-07-26 验证：Weaviate Cloud 的免费层（10 万对象、1 个集合、7 天备份）比 Pinecone Starter 更慷慨，Flex 月付套餐从 $45 起，按向量维度、存储、备份三个独立维度计费。
